# 西方哲学思想地图

一张可交互的西方哲学关系图：从笛卡尔到查尔莫斯，68 位哲学家、125 条思想关系。它的目标是帮助学生和感兴趣的人**看清脉络**，不追求面面俱到。

## 怎么读这张图

- **横向是传统。** 左边是英美传统（经验论 → 分析哲学、实用主义），中间是政治哲学和德国古典哲学 → 马克思主义，右边是欧陆传统（唯理论 → 现象学、存在主义、结构主义、精神分析）。
- **纵向是时间。** 越往下越接近当代，17–18 世纪被压缩，20 世纪被拉伸。
- **箭头 A → B** 表示 B 承接或回应了 A。关系分为继承、批判、转化、影响、呼应五种。

## 功能

| 功能 | 说明 |
|---|---|
| 入门 / 完整 | 入门模式只显示 30 位核心人物，先搭框架，再切换到完整模式 |
| 他在追问 | 每位哲学家配一个他要回答的问题，先懂问题，再看答案 |
| 专题导览 | 6 条线索逐站讲解，如“知识从哪里来”“语言转向的两条道路” |
| 争论对照 | 8 组经典论战左右并排：立场、论证、分歧关键、思考题 |
| 术语表 | 81 条术语，附原文、白话解释和相关人物；正文里的术语可以直接点开 |
| 时间轴 | 拖动或播放，看思想史一步步展开 |
| 思想路径 | 任选两人，查看他们之间是怎样一步步联系起来的 |

## 使用

用浏览器直接打开 `index.html` 即可，不需要安装任何东西。也可以在本目录启动一个本地服务器：

```bash
python3 -m http.server
```

在地址后加 `#kant` 这样的锚点，可以直接定位到某位人物。

## 修改内容

所有数据都在 `index.html` 的 `<script>` 里：

- `NODES`：人物
- `LINKS`：关系
- `POS`：人物在地图上的横向位置
- `TOURS`：专题导览
- `DEBATES`：争论对照
- `TERMS`：术语表

## 关于内容

- 人物概述、术语解释、争论梳理和关系注释都是自撰的概括，参考了通行的哲学史教材和公开百科的观点，没有照搬原文。
- 关系标签是对复杂思想史的简化，适合入门搭框架，不能替代原著和专业研究。欢迎在 Issues 里指出错误。
- 头像只使用公有领域或自由授权的图片，出处见 [`avatars/CREDITS.md`](avatars/CREDITS.md)。暂时没有头像的人物，会以姓氏首字代替。
